# Nebula 🌌

Космический мессенджер: Vite + React + TypeScript + Supabase.
Вход по 6-значному коду на почту, отдельная кнопка входа для создателя,
фиолетовое 3D-стекло и бейдж-чёрная дыра «СОЗДАТЕЛЬ».

---

## 1. Поставить Node.js (один раз)

Node на компьютере сейчас нет — без него `npm` не работает.

1. Открой <https://nodejs.org> → кнопка **LTS** → скачай установщик.
2. Windows: `.msi`, запусти, жми Next везде (галочку «Add to PATH» не снимай).
   macOS: `.pkg`, тоже Next.
3. **Закрой и снова открой терминал** (это важно — PATH обновляется только
   в новых окнах).
4. Проверка:

```bash
node -v     # должно быть v20.x или выше
npm -v      # должно быть 10.x или выше
```

Если пишет «команда не найдена» — терминал не перезапустил, либо при
установке сняли галочку PATH. Переустанови, не снимая её.

| Команда | Что делает |
|---|---|
| `npm run dev` | запускает dev-сервер (для разработки) |

Остановить сервер: `Ctrl + C` в терминале.

## 3. Подключить Supabase

Ключи уже вшиты в `src/lib/config.ts`, но текущий адрес проекта
`pbmkppqobjnnvhuvigd.supabase.co` **не существует** (DNS не находит его).
Значит нужно создать проект заново и подставить новые значения.

### 3.1 Создать проект

1. <https://supabase.com/dashboard> → **New project**.
2. Имя `nebula`, регион ближе к тебе, пароль БД любой (он нужен только
   для psql, приложению не требуется).
3. Дождись, пока проект поднимется (~1–2 минуты).

### 3.2 Взять URL и ключ

**Project Settings → API**:

- **Project URL** → скопируй в `SUPABASE_URL`;
- **Project API keys → anon public** → скопируй в `SUPABASE_ANON_KEY`.

```ts
// src/lib/config.ts
export const SUPABASE_URL = 'https://твой-ref.supabase.co'
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...'
```

`anon`-ключ можно держать в коде — он публичный по задумке Supabase, доступ
к данным всё равно режут правила RLS. А вот `service_role` в браузер
класть **нельзя никогда**.

### 3.3 Выполнить SQL

**SQL Editor → New query** → вставь содержимое `supabase/schema.sql` → **Run**.

Создадутся таблицы `profiles`, `chats`, `chat_members`, `messages`,
триггер автосоздания профиля, правила RLS и подписка Realtime.
Твоя почта `Kirillerman28@gmail.com` автоматически получит
username `kirill`, имя `Kirill` и флаг `is_creator = true`.

### 3.4 Включить вход по коду (самый важный пункт!)

**Authentication → Providers → Email** — включён (по умолчанию да).
**Authentication → Email Templates → Magic Link** — замени шаблон на этот:

```html
<h2>Код для входа в Nebula</h2>
<p>Твой код:</p>
<p style="font-size:28px;font-weight:700;letter-spacing:6px">{{ .Token }}</p>
<p>Код действует 60 минут. Если ты не запрашивал вход — просто игнорируй письмо.</p>
```

Почему это критично: по умолчанию Supabase присылает **ссылку**, а не код.
`{{ .Token }}` — это и есть те самые 6 цифр, которые проверяет приложение
(`verifyOtp`). Без этой строчки письмо придёт, но вводить будет нечего.

> Есть ещё шаблон **Confirm signup** — для входа по коду он не нужен,
> но если хочешь красивое письмо и там, вставь такой же текст с `{{ .Token }}`.

## 4. Как проверить

1. `npm run dev` → открыть `http://localhost:5173`.
2. Вписать свою почту → «Получить код» → проверить почту (и «Спам»).
3. Ввести 6 цифр → должен открыться чат «Nebula HQ» с приветствием.
4. Рядом с именем — бейдж «СОЗДАТЕЛЬ» (чёрная дыра с вращающимся диском).
5. Написать сообщение — оно появится сразу. Открой вторую вкладку: сообщение
   прилетит и туда (это Realtime).
6. Выйти (иконка выхода слева сверху) → нажать **«Войти как Создатель»**.
   Первый раз пароля у аккаунта может не быть — приложение отправит код
   и после входа само назначит пароль из `config.ts`. Дальше кнопка
   работает мгновенно, без письма.

Если Supabase недоступен, на экране входа появится предупреждение,
а кнопка **«Посмотреть демо без сервера»** покажет интерфейс на локальных данных.

## 5. Как это работает (карта для обучения)

**Поток входа по коду**

```
AuthPage (ввёл почту)
  → auth.requestCode()            → supabase.auth.signInWithOtp({ email })
  → Supabase шлёт письмо с {{ .Token }}
AuthPage (ввёл 6 цифр)
  → auth.verifyCode()             → supabase.auth.verifyOtp({ email, token, type: 'email' })
  → Supabase выдаёт сессию (JWT) и кладёт её в localStorage
  → auth.loadProfile()            → select из profiles
  → me = AppUser                  → App.tsx видит me и пускает на /chats
```

**Кнопка создателя** (`loginAsCreator` в `src/lib/auth.tsx`):

1. `signInWithPassword` с почтой и паролем из `config.ts` — быстро и без письма;
2. если пароля у аккаунта нет — фолбэк на обычный код на почту;
3. после любого успешного входа создателя `syncCreatorPassword` тихо
   назначает пароль через `updateUser({ password })`, чтобы шаг 1 работал всегда.

⚠️ Пароль в коде виден любому, кто откроет DevTools и заглянет в бандл.
Для локального теста это нормально, но **не выкладывай эту сборку в публичный
интернет как есть** и не используй пароль, который где-то ещё нужен.

**Чаты**

`ChatsPage` загружает: мои чаты (`chat_members` → `chats`), сообщения,
профили. Отправка = `insert` в `messages`, доставка = подписка Realtime.
Если чатов нет, приложение само создаёт «Nebula HQ» (`ensureStarterChat`).

**Ошибки** — `src/lib/errors.ts`: Supabase отвечает по-английски, функция
`ruError()` переводит на человеческий.

## 6. Где менять цвета и внешний вид

Всё оформление — один файл `src/styles/global.css`. Начни с блока `:root`
в самом верху: там переменные.

```css
:root {
  --violet-500: #8b5cf6;   /* основной фиолетовый */
  --magenta: #d946ef;      /* акцент, неон */
  --bg-0: #05030c;         /* самый тёмный фон */
  --text: #f3eeff;         /* основной текст */
  --stroke: rgba(167, 139, 250, 0.16);  /* тонкие рамки */
}
```

| Что хочется | Где смотреть |
|---|---|
| фон и туманности | `.space`, `.space__blob--violet/magenta/indigo` |
| звёзды | `.space__stars--far` / `--near` (это `box-shadow`, а не картинки) |
| стеклянные карточки | `.glass-card`, `.glass-panel` |
| 3D-кнопки | `.btn--primary`, `.btn--creator` — секрет в `box-shadow: 0 5px 0` |
| чёрная дыра | `.blackhole__core`, `__ring`, `__halo` + `@keyframes bh-spin` |
| сообщения | `.bubble--in`, `.bubble--out` |
| мобильная версия | `@media (max-width: 880px)` |

Размер бейджа: `<CreatorBadge size="sm" | "md" | "lg" />` и
`withLabel={false}` — только чёрная дыра, без подписи.

### Кнопка входа создателя — золотая чёрная дыра (утверждённый дизайн)

Финальный вид: чёрная дыра как в «Интерстелларе» — золотой раскалённый диск,
диагональная полоса «ребром» и размытое кольцо-«колесо» вокруг чёрной тени.
Надпись «СОЗДАТЕЛЬ» появляется при наведении.

Разметка: `src/components/CreatorButton.tsx`.
Стили: блок `11б. КНОПКА-ЧЁРНАЯ ДЫРА` в `src/styles/global.css`, слои по порядку:

| Слой | Класс | Что это |
|---|---|---|
| свечение | `.bh-btn__glow` | мягкий золотой ореол вокруг |
| кольцо | `.bh-btn__ring` | «загнутый» гравитацией диск вокруг тени |
| крылья | `.bh-btn__lobe--left/right` | точки, где полоса вливается в кольцо |
| тень | `.bh-btn__sphere` | горизонт событий, чёрный |
| фотонное кольцо | `.bh-btn__photon` | тонкая яркая окружность по краю тени |
| полоса | `.bh-btn__stick` | диск «ребром», диагональ −36° |

Если захочешь докрутить:
- угол полосы — `rotate(-36deg)` в `.bh-btn__stick` и `.bh-btn__lobe`;
- размер дыры — `width/height: 150px` у `.bh-btn__hole`;
- цвет и жар — переменные `--bh-hot`, `--bh-gold`, `--bh-amber`, `--bh-orange`,
  `--bh-deep` в `.bh-btn`;
- резкость — `filter: blur(...)` у кольца, полосы и «крыльев» (меньше = резче).

## 7. Если что-то не работает

| Симптом | Причина и лечение |
|---|---|
| `node`/`npm` не найдены | Node не установлен или терминал старый → переустанови Node, открой новый терминал |
| «Supabase не отвечает» на экране входа | Неверный `SUPABASE_URL` в `config.ts`, проект удалён/на паузе. Скопируй Project URL заново |
| Письмо приходит, но кода в нём нет | Не заменён шаблон Magic Link → добавь `{{ .Token }}` (пункт 3.4) |
| «Код неверный или истёк» | Код одноразовый и живёт 60 минут; запроси новый |
| «Слишком часто» | Лимит Supabase на отправку писем; подожди минуту |
| Ошибка `row-level security` | Не выполнен `schema.sql` или выполнен частично → прогони скрипт целиком |
| Пустой список чатов | Так и должно быть при первом входе: приложение создаст «Nebula HQ» само. Если не создаёт — смотри консоль браузера (F12) |
| Кнопка создателя просит код | У аккаунта ещё нет пароля. Введи код один раз — приложение назначит пароль, и дальше кнопка будет мгновенной |

Смотреть ошибки: `F12` → вкладка **Console** и **Network**.
